📋 QUICK START (4 Easy Steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🗄️  SETUP MONGODB
   ├─ Go to: mongodb.com/cloud/atlas
   ├─ Create free account and M0 cluster
   ├─ Create database user (username + password)
   ├─ Get connection string: mongodb+srv://...
   └─ Copy the connection string

2. 📝 CREATE .env FILE
   ├─ In the backend/ folder, create file named: .env
   ├─ Add these 3 lines:
   │  PORT=8000
   │  MONGODB_URI=paste_your_mongodb_uri_here
   │  NODE_ENV=production
   └─ Save the file (DO NOT commit this to git!)

3. 🧪 TEST LOCALLY
   ├─ Run: npm run install-all
   ├─ Run: npm start
   ├─ Visit: http://localhost:8000
   ├─ Test registration, login, and contact form
   └─ If all works, proceed to step 4

4. 🌍 DEPLOY TO CLOUD
   ├─ Choose ONE platform:
   │  • Render.com (Easiest) ⭐ RECOMMENDED
   │  • Railway.app (Modern)
   │  • Heroku (Classic)
   │  • Fly.io (Fast)
   └─ See QUICK_DEPLOY.md for step-by-step guide
