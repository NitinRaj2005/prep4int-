HOW IT ALL WORKS TOGETHER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    BROWSER                          YOUR SERVER                  DATABASE
    ───────                          ──────────                  ────────

    User visits
    https://app.com
           │
           ▼
    ┌────────────────────────┐
    │ GET /                  │──────▶ express.get("/")
    └────────────────────────┘       ├─ Renders register.hbs
                                     └─ Returns HTML
           ◀─────────────────────────┘

    User submits registration
    POST /register-data
           │
           ▼
    ┌────────────────────────┐
    │ POST /                 │──────▶ app.post("/")
    │ {email, password, ...} │       ├─ Validates data
    └────────────────────────┘       ├─ Saves to MongoDB
                                     │  (MONGODB_URI from .env)
                                     └─ Renders index.hbs
           ◀─────────────────────────┘

    User visits static page
    GET /que.html
           │
           ▼
    ┌────────────────────────┐
    │ GET /que.html          │──────▶ express.static()
    └────────────────────────┘       ├─ Serves /frontend/que.html
                                     └─ Loads CSS & images
           ◀─────────────────────────┘


DEPLOYMENT FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PREPARE (Local)
   ├─ npm run install-all
   ├─ Create .env file
   ├─ npm start (test)
   └─ All works ✓

2. PUSH (Local → GitHub)
   ├─ git add .
   ├─ git commit -m "Ready"
   └─ git push origin main
        ║
        ▼ (GitHub webhook)

3. DEPLOY (GitHub → Render/Heroku)
   ├─ Platform detects push
   ├─ Runs: cd backend && npm install
   ├─ Runs: cd backend && node app.js
   ├─ App starts on PORT 8000
   └─ Server listens for requests

4. SERVE (Server → Users)
   ├─ User visits https://app.onrender.com
   ├─ Browser requests /
   ├─ Server returns register.hbs
   ├─ Browser renders HTML, CSS, JS
   └─ App is live!

AFTER DEPLOYMENT - WHAT'S RUNNING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

On Render/Heroku:

    Node.js Runtime
    │
    ├─ Reads MONGODB_URI from environment
    │
    ├─ Starts Express server
    │  ├─ Listens on PORT 8000
    │  ├─ Serves /backend/views/*.hbs templates
    │  ├─ Serves /frontend/* static files
    │  └─ Handles API routes
    │
    └─ Connects to MongoDB Atlas
       ├─ Stores user registrations
       ├─ Stores login data
       └─ Stores contact form messages


TROUBLESHOOTING CHECKLIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

App won't start?
  ✓ Check MONGODB_URI is correct
  ✓ Check .env file exists on platform
  ✓ Check app.js for syntax errors

404 errors for CSS/images?
  ✓ Check frontend/ folder exists
  ✓ Check staticPath in app.js
  ✓ Check browser console for 404s

Can't register users?
  ✓ Check MongoDB connection
  ✓ Check MONGODB_URI in environment
  ✓ Check network in MongoDB Atlas (0.0.0.0/0)

Forms not working?
  ✓ Check app.post() routes
  ✓ Check form field names match
  ✓ Check request body parsing
